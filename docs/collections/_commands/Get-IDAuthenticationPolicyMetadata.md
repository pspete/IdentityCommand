# Get-IDAuthenticationPolicyMetadata

## SYNOPSIS
Get authentication policy metadata

## SYNTAX

```
Get-IDAuthenticationPolicyMetadata [<CommonParameters>]
```

## DESCRIPTION
Retrieve metadata describing the settings, options, and fields available when building or editing authentication policies for the tenant.

## EXAMPLES

### Example 1
```
PS C:\> Get-IDAuthenticationPolicyMetadata
```

Return the tenant's authentication policy metadata.
