# Get-IDSCIMServiceProviderConfig

## SYNOPSIS
Get the SCIM Service Provider configuration

## SYNTAX

```
Get-IDSCIMServiceProviderConfig [<CommonParameters>]
```

## DESCRIPTION
Returns the tenant's SCIM Service Provider configuration, describing supported SCIM features.

## EXAMPLES

### Example 1
```powershell
PS C:\> Get-IDSCIMServiceProviderConfig
```

Returns the tenant's SCIM Service Provider configuration.
