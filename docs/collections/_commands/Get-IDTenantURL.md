# Get-IDTenantURL

## SYNOPSIS
Get tenant URL

## SYNTAX

```
Get-IDTenantURL [<CommonParameters>]
```

## DESCRIPTION
Returns the tenant's URL configuration, including its default id.cyberark.cloud URL and any custom cnames registered against it.

## EXAMPLES

### Example 1
```powershell
PS C:\> Get-IDTenantURL
```

Return the tenant's URL configuration
