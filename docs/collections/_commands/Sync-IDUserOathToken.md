# Sync-IDUserOathToken

## SYNOPSIS
Resynchronize a TOTP/HOTP OATH token

## SYNTAX

```
Sync-IDUserOathToken [-TokenId] <String> [-FirstCode] <String> [-SecondCode] <String> [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Resynchronizes a drifted TOTP or HOTP OATH hardware/software token by submitting two consecutive
codes generated by the device.

## EXAMPLES

### Example 1
```powershell
PS C:\> Sync-IDUserOathToken -TokenId 'sometokenid' -FirstCode '123456' -SecondCode '654321'
```

Resynchronizes the specified OATH token.
