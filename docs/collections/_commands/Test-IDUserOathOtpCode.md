# Test-IDUserOathOtpCode

## SYNOPSIS
Validate an OATH OTP code

## SYNTAX

```
Test-IDUserOathOtpCode [-ID] <String> [-OtpCode] <String> [[-UseOathDefaults] <String>]
 [<CommonParameters>]
```

## DESCRIPTION
Validates a one-time password code generated by a user's OATH token.

## EXAMPLES

### Example 1
```powershell
PS C:\> Test-IDUserOathOtpCode -ID 'a1b2c3d4-0000-0000-0000-000000000000' -OtpCode '123456'
```

Validates the given OTP code for the specified user.
