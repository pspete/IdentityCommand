# Get-IDAuthenticationPolicyModifier

## SYNOPSIS
Get available authentication policy modifiers

## SYNTAX

```
Get-IDAuthenticationPolicyModifier [<CommonParameters>]
```

## DESCRIPTION
Retrieve the list of authentication policy modifiers (condition types, such as network, device, or risk-based rules) available for building authentication policy filters/conditions in the tenant.

## EXAMPLES

### Example 1
```
PS C:\> Get-IDAuthenticationPolicyModifier
```

Return the available authentication policy modifiers.
