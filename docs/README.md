# IdentityCommand docs site

Jekyll site (bulma-clean-theme) for IdentityCommand and its sibling `IdentityCommand.*` modules, published to GitHub Pages by [.github/workflows/docs.yml](../.github/workflows/docs.yml).

| Path | Content |
| --- | --- |
| `/` | IdentityCommand pages; command help in `collections/_commands` |
| `/<Module>/` | Sibling module pages, copied from the sibling repo's `docs/` |
| `/<Module>/commands/` | Sibling command help, copied from the sibling repo's `docs/collections/_commands` |
| `/releases/` | IdentityCommand release notes in `collections/_posts` |
| `/<Module>/releases/` | Sibling release notes, copied from the sibling repo's `docs/collections/_posts` into `collections/_posts/<Module>/` |
| `/<Module>/releases/<version>/` | Redirect to the release note with that `version` (full or major.minor) |
| `/releases/all/` | Release notes for all modules |
| `/search/` | Pagefind search, indexed after the Jekyll build |

Sibling content is copied in by `_tools/sync_modules.rb`; copied folders are git-ignored.

## Local preview

Requires Ruby 3.x (`winget install RubyInstallerTeam.RubyWithDevKit.3.3`).

```shell
cd docs
bundle install
ruby _tools/sync_modules.rb            # local sibling clones beside this repo
bundle exec jekyll serve               # http://localhost:4000/IdentityCommand/
```

`sync_modules.rb` options: `--source DIR` (folder holding sibling clones), `--suffix SUFFIX` (e.g. `-docs-site` for worktrees), `--branch BRANCH` (shallow clone from GitHub instead).

To preview unpublished modules too, `--preview` copies every local `IdentityCommand.<Name>` clone with `docs/collections/_commands` that is not yet in `_data/menus.yml`, and writes `_config.preview.yml` (git-ignored) with their collections, defaults and menu entries:

```shell
ruby _tools/sync_modules.rb --preview
bundle exec jekyll serve --config _config.yml,_config.preview.yml
```

Running the sync without `--preview` removes them again.

Search needs the Pagefind index, which `jekyll serve` deletes on rebuild:

```shell
bundle exec jekyll build
npx -y pagefind --site _site
bundle exec jekyll serve --skip-initial-build --no-watch
```

## Sibling module docs

A sibling repo's `docs/` holds:

- `index.md` - module landing page
- `getting-started.md` - install and authentication
- `collections/_commands/*.md` - platyPS command help, one file per command
- `collections/_posts/YYYY-MM-DD-<slug>.md` - release notes, one file per release, with `title`, `date` and optional `version` front matter
- `media/` - images, referenced as `/<Module>/media/...`

Pages need no layout or menubar front matter; defaults are applied by path.
Links between pages use `{{ '/<Module>/page/' | relative_url }}`.

Copy [_tools/docs-dispatch.yml](_tools/docs-dispatch.yml) to the sibling's `.github/workflows/` and add secret `DOCS_DISPATCH_TOKEN` (fine-grained PAT, `pspete/IdentityCommand` only, Contents: read and write) so docs changes rebuild the site.

## Adding a module

For module `IdentityCommand.XYZ`:

1. `_data/navigation.yml` - add `name`, `link: /XYZ/`, `module: XYZ`.
2. `_data/menus.yml` - add key `XYZ` with `label`, `repo`, `commands: XYZ`, `prefix: XYZ`, `pinned` (e.g. `Connect-XYZTenant`), `description`, `image` and `menu`.
3. `_config.yml` - add collection `XYZ` (`output: true`, `permalink: /XYZ/commands/:title/`) and the two `defaults` entries (path `XYZ`, type `XYZ`) matching SCA/SIA.
4. Add `docs/` and the dispatch workflow to the sibling repo.

The command index page at `/XYZ/commands/` is generated by `_plugins/commands.rb`.
Once the module has release notes, `_plugins/releases.rb` generates `/XYZ/releases/` and adds a Release Notes menu item.

## Workflow

Triggers: push to `main` touching `docs/`, `repository_dispatch` type `docs-updated`, manual run.
Sibling branch: manual `branch` input, else repository variable `DOCS_SIBLING_BRANCH`, else `main`.
Deploys only from `main`.
